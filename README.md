# Run

Self-hosting made simple.

## Services

| Service | Description |
|---------|-------------|
| [run](https://github.com/omnidotdev/run-cli) | CLI |
| [run-site](https://github.com/omnidotdev/run-site) | Website |

## Getting Started

1. Copy configuration template:

   ```sh
   cp services.yaml.template services.yaml
   ```

2. Start development:

   ```sh
   tilt up
   ```
